# Przeniesienie Tekmy z JDG do sp. z o.o. — lista (przygotować przed pierwszym dużym klientem)

Zasada: wszystko, co ma być przenośne, zakładaj od początku na osobnych kontach Tekmy, nie na kontach Creative Vision.

## Konta i usługi (zmiana właściciela / dane firmy)
- [ ] Domena tekma.app i tekma.* — rejestrator: przenieść właściciela (osobny kontakt firmowy)
- [ ] Supabase — organizacja Tekma (nie osobista), transfer projektu przy zmianie podmiotu, dane do faktur
- [ ] GitHub — repo pod organizacją Tekma, nie osobistym kontem
- [ ] Hosting (cyberfolks lub nowy) — umowa i faktury na nowy podmiot
- [ ] Poczta/SMTP (mail.tekma.app) — dane rozliczeniowe
- [ ] Stripe / bramka płatności — nowe konto dla spółki (KYC), przepięcie klucza; subskrypcje klientów wymagają migracji
- [ ] Narzędzia: Figma, Semrush, API AI (Anthropic itd.) — przepiąć subskrypcje i faktury
- [ ] Skrzynka kontakt@tekma.app, konto Google/M365 firmowe

## Prawo i umowy
- [ ] Przeniesienie praw autorskich do kodu, marki, logo i treści na spółkę (umowa cesji / wkład niepieniężny — z prawnikiem)
- [ ] Znak towarowy: zgłoszenie na spółkę (EUIPO/UPRP), jeśli jeszcze niezgłoszony
- [ ] Umowy z klientami: aneks/cesja na spółkę; powiadomienie klientów
- [ ] Nowe umowy powierzenia (art. 28) i lista podwykonawców na nowy podmiot
- [ ] Regulamin i polityka prywatności: nowy administrator/dane spółki
- [ ] Rejestr czynności przetwarzania i ewentualne zgłoszenia — na nowy podmiot
- [ ] Ubezpieczenie OC/cyber na spółkę
- [ ] Umowa między Tobą a spółką (rola, wynagrodzenie, ewentualnie licencja na kod do czasu cesji)

## Finanse i księgowość
- [ ] Wybór formy opodatkowania (CIT 9%/19% lub estoński CIT) z księgowym
- [ ] Rachunek firmowy, VAT, e-faktury, księgowość pełna
- [ ] Wycena wkładu IP / koszt wytworzenia (konsekwencje podatkowe cesji z JDG — z księgowym)
- [ ] Rozliczenie zobowiązań i abonamentów JDG, zamknięcie lub wygaszenie wątków Tekmy w JDG

## Techniczne
- [ ] Zmiana danych podmiotu w stopce, regulaminie, e-mailach, fakturach z aplikacji
- [ ] Klucze/sekrety: rotacja po zmianie właściciela kont
- [ ] Dokumentacja dostępu (kto ma admina) — min. dwie osoby/odzyskiwanie
